# Technical Event Participation Approval & Attendance Monitoring Portal

A web-based portal designed to simplify the process of verifying student attendance eligibility and managing approvals for participation in technical events.

## 📌 About the Project

The **Technical Event Participation Approval & Attendance Monitoring Portal** helps universities manage student requests to participate in technical events through a structured and transparent approval workflow.

The system allows attendance records to be imported and validated, checks student eligibility against a predefined attendance threshold, and enables proctors and event in-charges to review and process participation requests.

## 🎯 Key Features

- **Attendance Management:** Import and validate student attendance records using Excel or CSV files.
- **Eligibility Verification:** Calculate attendance percentages and determine eligibility based on a predefined threshold.
- **Student Requests:** Allow students to submit requests to participate in technical events.
- **Proctor Review:** Enable proctors to review student requests and provide recommendations.
- **Final Approval:** Allow the technical event in-charge to make the final decision.
- **Audit Trail:** Maintain a record of important actions and approval decisions.
- **Role-Based Access:** Provide different permissions and functionalities for students, proctors, and event in-charges.

## 👥 User Roles

- **Student:** Views attendance eligibility and submits event participation requests.
- **Proctor:** Reviews requests and provides recommendations.
- **Technical Event In-Charge:** Reviews recommendations and makes final approval decisions.
